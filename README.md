## Main Features
<a id="main-features"></a>

### Core Functionality
- **File Information Display** — Filealyzer provides extensive details about any file, including its name, location, size, and modification dates, offering a complete overview at a glance.
- **Checksum Calculation** — The tool calculates CRC-32 and MD5 checksums for files, enabling users to verify file integrity easily and ensure that files have not been tampered with.
- **Executable Analysis** — Users can identify if a file is an executable and view its associated resources, such as icons and text, giving insights into its functionality.
- **PE Header Inspection** — The application reveals the PE header for executable files, describing the file's structure and providing vital information for developers.
- **Hex Dump Feature** — Filealyzer includes a hex dump option that allows users to view raw file data, with the ability to search for specific patterns or strings.

### Advanced Capabilities
- **Export Options** — After generating a report, users can store it in various formats, including text, HTML, or XML, ensuring compatibility with different workflows.
- **Clipboard Integration** — The tool offers an efficient way to copy file analysis results directly to the clipboard, allowing for quick sharing and documentation.
- **Partial Data Copying** — Users can perform a selective copy of the analysis data, facilitating the extraction of only the necessary information for their needs.
- **Context Menu Integration** — Filealyzer can be accessed directly from the Windows Explorer context menu, providing a seamless user experience for file analysis.
